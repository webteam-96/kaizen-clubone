# Kaizen ClubOne prototypes

Clickable prototypes for Kaizen ClubOne, the clubhouse platform for entry, amenity booking, wallet and QR access.

Open `prototype/index.html` in a browser. No server or build step is needed.

- `prototype/app/` is the member app (shown in a phone frame on desktop).
- `prototype/admin/` is the admin portal with station mode. Pick a role on the login screen.
- `prototype/assets/` holds photos (Unsplash, see `img/CREDITS.txt`), logo concepts and screenshots.
- `design.md` is the design reference.

All data is sample data. Bookings made in the app appear in the admin when both are open in the same browser.
